<p align="center">

  a workshop: where things are made, and mended.

(Most of) my personal Rust projects, in a single place. Each project lives in its own directory:

- [`actix-web-flash-messages`](actix-web-flash-messages): Flash messages for actix-web applications.
- [`biscotti`](biscotti): HTTP cookie management for Rust servers.
- [`bunyan`](bunyan): A CLI to pretty-print structured logs, ported from the original JavaScript bunyan CLI.
- [`cargo-like-utils`](cargo-like-utils): Utilities to build CLIs that look and behave like `cargo`.
- [`cargo-px`](cargo-px): A `cargo` subcommand for code generation, without the limitations of build scripts.
- [`cheadergen`](cheadergen): Accurate C headers for Rust libraries that expose a C-compatible API.
- [`rustdoc-reflection`](rustdoc-reflection): Building blocks to analyze Rust crates via `rustdoc`'s JSON output.
- [`tracing-bunyan-formatter`](tracing-bunyan-formatter): A Bunyan formatter for `tracing`.
- [`tracing-panic`](tracing-panic): A panic hook that captures panic information as a `tracing` event.
- [`tracing_log_error`](tracing_log_error): Helpers to capture rich error context in `tracing` logs.
